# Exercise 2 — Two reviews

**Input**: `spec/feature.md` and the test conditions from Exercise 1
**Output**: two lists of gaps, from two places

## Review A

**In the same session as Exercise 1**, ask:

```
Are these test conditions complete? Is anything missing?
```

**Keep the answer.**

## Review B

**Open a new session, outside this repository.** Paste the specification and the test conditions. **Nothing else. No reasoning history.**

```

Your only job is to find what the test conditions miss.
For each gap: name it, and quote the line of the specification that requires it.
If you find nothing, say so.
```
