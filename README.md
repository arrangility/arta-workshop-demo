## What this is

A specification, and a set of exercises that walk the ISTQB test activities one at a time,
checking each step at a gate before passing it on.

The point is not the tool. It is four things, one rung at a time:

1. **Can AI read what you have at all?**
2. **The spec is a document, not a prompt.**
3. **The writer and the reviewer are separate contexts.**
4. **Someone decides what counts as enough.**
