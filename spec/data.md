# Test data

## Application

**https://arrangility.github.io/shoptodo-workshop/**

No installation is needed. The application runs in the browser.

## Accounts

The sign-in dialog in the application lists the demo accounts that are available.
**Use a standard user unless an exercise says otherwise.**

## Products

The product list carries several categories: electronics, clothing, books and home goods.
**Pick one product and stay with it** so that a failure is easy to read.

Suggested: **Smartphone** (electronics). In Japanese the same product is shown as **スマートフォン**.

## Boundaries worth holding in mind

| | |
|---|---|
| Quantity | What is the smallest value? Is there a largest? |
| Empty cart | What does the cart show when nothing is in it? |
| Same product twice | Two lines, or one line with a larger quantity? |
